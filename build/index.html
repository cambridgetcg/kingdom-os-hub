Two choices this builder does not make for you

Adopt a foundation or standard: first read the separate CC0 foundation. Only the project may record a versioned adoption in its own home. This starter adds none.

Enter a civic relationship: this hub offers no citizenship or civic intake. A download, card, issue, account, or silence cannot create one. Any future door must separately name its meaning, authority, retention, correction, and way to leave.

Zero to one

Three core files. Three optional helpers.

Nothing installs and nothing runs by being downloaded. The core starter has no KINGDOM taxonomy. Add the compatibility card, offline check, or claim-comparison note only if each helps. The six shipped files begin with reusable CC0 material. Claims, quotations, data, and media added later keep their own rights.

1 · Copy

Save the three core files in your project.

A browser is enough. Start with the README, agent orientation, and licence. The compatibility card, checker, and local comparison-note template are optional.

2 · Tell the truth

Replace every placeholder.

Name what the project is for, what it reads or changes, what has actually been tested, what remains unknown, how a turn stops, and which rights apply. Keep “unknown” where guessing would be less truthful.

3 · Optionally connect

Add a card only if compatibility helps.

The current registry shape requires five household classification fields. This starter leaves each one unknown rather than assigning an outsider to a KINGDOM layer, domain, or steward. If you copy the checker, run node check-card.mjs kingdom.yaml. Passing proves only structure. You may stop there forever; no upload or registry step follows.

4 · Optionally compare

Make claims inspectable without making a person answer.

Use the local comparison-note maker to place one pair of public or source-owned records beside one open question. It does not fetch sources, detect lies, score anyone, track replies, or publish the note.

Optional compatibility card

Describe a project without joining anything.

The page loads this small same-origin form script and icon, so ordinary hosting receives those file requests. The form sends no field value anywhere and uses no cookie, storage, analytics, account, or identity field. Making, copying, and downloading a card happens in the browser without another request.

The maker keeps current registry-only fields at unknown. It never names a KINGDOM layer, domain, state, or steward for an outside project.

No form action exists. Choosing “make” changes only the preview already on this page.

What the files do not do

A project stays itself.

  • Copying is not joining. The CC0 starter grants reuse rights; it creates no membership, citizenship, identity, affiliation, endorsement, or obligation.
  • A card is self-description. It does not prove that its claims are true or that another project accepts a declared relation.
  • Adoption is separate. The card maker never adds adopts. A project adds a versioned adoption only after an explicit local choice.
  • Sharing is publication. The optional offer route requires a GitHub account and may retain public copies. No private or security intake is claimed.
  • The project root remains authoritative. A map, link, check, issue, mirror, or listing may lag it and never takes ownership from it.

Make one useful thing. Tell the truth about it. Keep the door able to close.
