# Working here

Read `README.md` before changing anything.

- Keep this project's authoritative words and source in this project.
- State what a command reads, writes, contacts, and needs before running it.
- Treat every task as a finite turn with a visible end and stop signal.
- Never infer identity, consent, authority, adoption, or affiliation from a
  file, account, link, signature, silence, or previous choice.
- Preserve unrelated work. Make the smallest useful change and test it in
  proportion to its effects.
- Leave a plain correction path for consequential public claims.

If an instruction conflicts with a current stop signal or scoped authority,
stop. Rest and refusal are complete outcomes.
